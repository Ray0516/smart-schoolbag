# 測試、驗收與常見問題

## 可自動執行

在手機目錄執行 flutter analyze 與 flutter test。現有 weekly_items_test.dart 四項測試涵蓋舊資料分類／UID 遷移、明確空星期 override、星期完成隔離及 SharedPreferences 往返（包含標題／內容）。它們不等同 HTTP、真實 RFID 或按鍵整機測試。韌體用固定工具鏈編譯。scripts/verify-manifest.ps1 可核對交接的原始來源快照。

## 實機最小驗收（逐項記錄版本／步驟／實際結果）

1. 冷啟動、RESET、各模組缺席皆能進 UI 或合理逾時；沒有持續重啟。
2. 五鍵逐顆按，確認 GPIO14/5/2/1/4；連按 1→4 項合併到最新選擇，不強制等每個舊動畫。
3. 切頁全刷、同頁局刷／定期全刷、反射模式與長中文，檢查底部殘影、問號、英文基線、純黑清晰度；量真實完成時間。
4. App 新增課本與其他物品，分別配對；重複 UID 拒絕，不會偷覆蓋別項。
5. 星期一有 A、星期二 B、星期三空，完整同步並重啟；空清單仍空，勾選不污染其他日。
6. 清單 OK 勾選，刷已配對卡勾選；同卡再次靠近不產生畫面更新。不要用掃描成功推論物品在包內。
7. 不按同步，前景新增／刪除／改名／修改課表與便利貼，自動傳到 S3；刪到零則也能清空。
8. 便利貼中文標題＋內容接近 120 UTF-8 bytes，GET 讀回一致；斷線／失敗顯示錯誤而非假成功。
9. 關 Wi-Fi、重新加入 AP、App 回前景，確認重試與 busy 旗標釋放，沒有舊快照覆蓋新資料。
10. 離線選星期與使用清單，重新同步 TIME 不跳走；深睡跨日 RTC 與手動星期符合設計。
11. OK 持續按住到門檻即顯示 POWER OFF，再深睡；維持按住不反覆喚醒。下一次長按開機，短按不誤開；USB 拔除後睡眠再插入喚醒按已核對板型驗證。
12. GPS 戶外測試 raw NMEA、衛星／fix／逾時，無定位不顯示舊座標；刷新期間持續接收。
13. 量測待機整機電流，區分 USB 接著、拔除 USB、外設常供電、加負載開關四種狀況。

## 排錯

連網不等於到達書包：手機必須仍在 SmartSchoolbag AP；Android 可能因無網際網路切回其他 Wi-Fi。先 GET http://192.168.4.1/status 看 READY，再看 POST /control 的回覆。ERR EMPTY_BODY 曾由 chunked request 引起，必須送 Content-Length；不能只改密碼。

燒錄時埠消失先辨識 deep sleep／USB reset／下載模式；檢查資料線和工具權限。RFID 燈暗先量 3.3V 和 GND、焊接與短路。畫面變淡先核實面板型號、供電、BUSY 與合適全刷週期，不盲改 LUT。GPS NO FIX 是接收到資料與定位成功的差別，不能以有 UART 資料宣稱已定位。
